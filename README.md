# mecmua Pinterest publishing site

Public images and landing pages for the mecmua Pinterest publishing stream.

- RSS feed: [https://mecmua.world/feed.xml](https://mecmua.world/feed.xml)
- Pin queue: `assets/pin-queue.csv`
- Product landing page template: `pin.html?id=<pin-id>`
- Each page links to its ShopMy destination and includes an affiliate disclosure.
- The GitHub Action regenerates `feed.xml` and `pins.json` when the queue changes.

The site is separate from the private mecmua archive. It contains only the public Pinterest product selections.
